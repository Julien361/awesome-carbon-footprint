## Website Carbon Calculators

| Tool | Type | Notes |
|------|------|-------|
| [Website Carbon Calculator](https://www.websitecarbon.com/) | Online | By Wholegrain Digital, estimates CO2 per page view |
| [Ecograder](https://ecograder.com/) | Online | Grades your site on sustainability + performance |
| [Carbon Badge](https://carbon-badge.com) | Online/Badge | Lightweight carbon calculator with embeddable badge for any website |
| [Beacon](https://digitalbeacon.co/) | Online | Carbon estimate + improvement suggestions |
| [GreenFrame](https://greenframe.io/) | CI/CD | Measures carbon footprint in development pipeline |
| [CO2.js](https://github.com/thegreenwebfoundation/co2.js) | Library | JavaScript library by The Green Web Foundation |

## Green Hosting

- [The Green Web Foundation](https://www.thegreenwebfoundation.org/) - Directory of green hosts
- [Green Web Check](https://www.thegreenwebfoundation.org/green-web-check/) - Check if a site uses green hosting
- [Infomaniak](https://www.infomaniak.com/) - Swiss ecological hosting
- [Greengeeks](https://www.greengeeks.com/) - 300% renewable energy match
- [Kualo](https://www.kualo.com/) - Carbon-neutral UK hosting

## Performance & Optimization

Good performance = lower carbon emissions. Every KB matters.

- [Lighthouse](https://developer.chrome.com/docs/lighthouse) - Performance auditing
- [WebPageTest](https://www.webpagetest.org/) - Detailed performance analysis
- [Squoosh](https://squoosh.app/) - Image compression
- [PurgeCSS](https://purgecss.com/) - Remove unused CSS
- [Bundlephobia](https://bundlephobia.com/) - Check npm package size impact

## Carbon APIs

- [CO2.js](https://github.com/thegreenwebfoundation/co2.js) - Estimate CO2 from data transfer
- [Climatiq API](https://www.climatiq.io/) - Emission factor database API
- [Carbon Interface](https://www.carboninterface.com/) - REST API for carbon estimates
- [Electricity Maps](https://www.electricitymaps.com/) - Real-time carbon intensity by region
- [Open Carbon API](https://docs.opencarbonapi.com/) - Open-source carbon calculation

## Badges & Widgets

## Sustainability Frameworks

- [Sustainable Web Design](https://sustainablewebdesign.org/) - Model for estimating emissions
- [W3C Web Sustainability Guidelines](https://www.w3.org/community/sustyweb/) - W3C community group
- [Green Software Foundation](https://greensoftware.foundation/) - Linux Foundation project
- [EU Green Claims Directive](https://environment.ec.europa.eu/topics/circular-economy/green-claims_en) - EU regulations on environmental claims
- [GreenClaims Scanner](https://greenclaims-scanner.com) - Tool to verify compliance with EU Green Claims Directive
